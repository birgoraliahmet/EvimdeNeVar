<h2 id="english">🇬🇧 English</h2>

**Evimde Ne Var?** (What's in my fridge/home?) is a React Native mobile application designed to help you decide what to cook based on the ingredients you already have at hand. It features a rich, built-in local database of delicious recipes, allowing you to find meal ideas completely **offline**.

### 🌟 Features
- **Smart Ingredient Selection:** Choose the ingredients you currently have in your kitchen.
- **Offline Recipe Matching:** The app instantly filters and suggests recipes you can make, without needing an internet connection.
- **Detailed Recipe View:** Get step-by-step instructions, preparation & cooking times, and exact measurements for each serving.
- **Fast & Responsive:** Built with React Native and Expo for a smooth, native-like experience on both iOS and Android.

### 📱 Screens
1. **Ingredient Selection (Evimde Ne Var?):** Select the ingredients you have.
2. **Recipe List (Sizin İçin Tarifler):** View the suggested recipes based on your selection.
3. **Recipe Details:** Read the full recipe, ingredients list, and step-by-step cooking instructions.

### 🛠️ Tech Stack
- React Native
- Expo
- React Navigation (Native Stack)

### 🚀 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/evimdenevar.git
   cd evimdenevar
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Start the Expo development server:**
   ```bash
   npm start
   ```
4. **Run on your device:** Use the Expo Go app on your physical device to scan the QR code, or press `a` for Android emulator / `i` for iOS simulator.

<h2 id="türkçe">🇹🇷 Türkçe</h2>

**Evimde Ne Var?**, evinizdeki mevcut malzemeleri seçerek ne yemek yapabileceğinizi bulmanıza yardımcı olan bir React Native mobil uygulamasıdır. İçerisinde yer alan zengin yerel tarif veritabanı sayesinde tamamen **çevrimdışı (internetsiz)** çalışır.

### 🌟 Özellikler
- **Akıllı Malzeme Seçimi:** Mutfağınızda olan malzemeleri kolayca seçin.
- **Çevrimdışı Tarif Eşleştirme:** İnternet bağlantısına ihtiyaç duymadan, seçtiğiniz malzemelerle yapabileceğiniz yemek tariflerini anında görün.
- **Detaylı Tarif Görünümü:** Her tarif için adım adım yapılış aşamaları, hazırlık/pişirme süreleri, porsiyon bilgisi ve malzeme ölçülerini inceleyin.
- **Hızlı ve Akıcı:** Hem iOS hem de Android cihazlarda sorunsuz bir deneyim için React Native ve Expo ile geliştirildi.

### 📱 Ekranlar
1. **Malzeme Seçimi (Evimde Ne Var?):** Elinizdeki malzemeleri işaretlediğiniz ana ekran.
2. **Tarif Listesi (Sizin İçin Tarifler):** Seçimlerinize uygun, yapabileceğiniz yemeklerin listelendiği ekran.
3. **Tarif Detayı:** Seçilen yemeğin yapılış adımlarını ve tam malzeme listesini içeren ekran.

### 🛠️ Kullanılan Teknolojiler
- React Native
- Expo
- React Navigation (Native Stack)
